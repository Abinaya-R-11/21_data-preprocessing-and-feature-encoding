# Data Preprocessing & Feature Encoding Pipeline

A practical machine learning preprocessing workflow implementing data cleaning, statistical imputation, data type casting, and categorical encoding techniques using Python, Pandas, and Scikit-Learn.

## 📌 Overview

Before building machine learning models, raw data requires systematic cleaning and transformation. This project demonstrates end-to-end data preparation on an environmental/weather dataset (environmental_data.csv), handling missing entries, standardizing inconsistent records, and converting categorical labels into numerical formats.
